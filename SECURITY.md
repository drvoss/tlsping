# Security Policy

## Supported versions

tlsping is pre-1.0 software. Security fixes are applied to the latest source
revision; older revisions are not supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when it is available.
If it is not available, open an issue asking for a private contact channel, but
do not publish exploit details, credentials, private URLs, or certificate
material.

tlsping sends repeated HTTP requests. Only measure endpoints you own or have
permission to test.
